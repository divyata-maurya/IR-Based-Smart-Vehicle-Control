# IR-Based Smart Vehicle Detection and Alert System

## About the Project
The IR-Based Smart Vehicle Detection and Alert System is an Arduino-based hardware and software project designed to detect obstacles using an Infrared (IR) sensor and generate visual and audio alerts.

The system uses an IR sensor to detect nearby obstacles. When an obstacle is detected, the Arduino UNO processes the sensor signal and activates an LED and a piezo buzzer to provide an alert.

## Objectives
- To detect obstacles using an IR sensor.
- To process sensor signals using Arduino UNO.
- To generate visual alerts using an LED.
- To generate audio alerts using a piezo buzzer.
- To understand the practical application of hardware and software integration.

## Hardware Components
1. Arduino UNO
2. IR Obstacle Detection Sensor
3. Relay Module
4. LED
5. Piezo Buzzer
6. 9V Battery
7. Toy Car
8. Connecting Wires

## Software Requirements
- Arduino IDE
- Arduino Programming Language (C/C++)

## Working Principle
1. The IR sensor emits infrared light.
2. When an obstacle is present, the reflected infrared light is detected by the sensor.
3. The sensor sends a digital signal to the Arduino UNO.
4. Arduino processes the received signal.
5. The LED and piezo buzzer are activated to indicate obstacle detection.

**Note:** The current demonstration provides visual and audio alerts. Automatic braking or stopping of the toy car is not implemented.
